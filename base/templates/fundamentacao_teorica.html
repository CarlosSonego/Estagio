Fundamentação Teórica

Esta aplicação sintetiza os resultados do Trabalho de Conclusão de Curso (TCC), que utiliza modelos de predição (Random Forest, KNN, XGBoost) para prever o resultado de uma partida do Campeonato Brasileiro de Futebol. Este trabalho utiliza os dados entre 2015 à 2023 para esta previsão.

1.Base de Dados

O modelo é alimento por dados do campeonato Brasileiro encontrados no Kaggle contendo dados de 2003 até 2024, e pelo Elo-Rating das equipes. Os dados passaram por uma fase de extração, cujo teor era encontrar erros nos dados do dataset, sendo por uns dos motivos a seguir:

  • Tuplas completamente vazias: Este foi o erro com maior ocorrencia, para resolver isso estas tuplas foram excluidas, no total os anos de 2003 até 2014 foram cortados além do ano de 2024;
  • Tuplas com atributo igual a None: Outro erro bastante comum foi da tupla conter o valor none, para corrigir isso foi utilizado a média desse atributo excluindo o None;
  • O atributo chutes no alvo: No ano de 2015 a 2016 este atributo estava vazio para corrigir isso foi adicionado a mão estes dados utilizando o site da ESPN como base de dados, mesmo utilizando o site da ESPN houve alguns jogos que não foi possível encontrar este valor, para não ficar vazio foi colocado o placar da partida como o total de chutes no alvo.

2.Modo de Avaliação

Para a avaliação dos modelos de predição ira ser utilizado a Acurácia como principal método avaliativo, em conjunto serão utilizados as seguintes métricas auxiliares:

  • Precision: Se refere ao número de exemplos que o modelo previu como sendo de uma classe e que realmente são, divididos pelo número total de exemplos previstos daquela classe pelo modelo;
  • Recall: Se refere ao número de exemplos que o modelo previu como sendo de uma classe e que realmente são, divididos pelo número total de exemplos previstos daquela classe;
  • F1-Score: O F1 Score é uma métrica que leva em consideração tanto o precision quanto o recall. Utilizando a seguinte fórmula:
\[ \text{Valor F1} = 2 \cdot \frac{\text{Precisão} \cdot \text{Recall}}{\text{Precisão} + \text{Recall}} \]

4.Shap

O método SHAP verifica o modelo após o treinamento. Este método atribui a cada entrada uma pontuação numérica que mostra o quanto ela aumentou ou diminuiu uma previsão em comparação com uma linha de base, sendo baseado nos valores de Shapley da teoria dos jogos cooperativos, que é uma forma de distribuir o ganho ou custo total entre vários participantes. Para esta pesquisa o método SHAP foi utilizado somente no Modelo de maior acurácia.
